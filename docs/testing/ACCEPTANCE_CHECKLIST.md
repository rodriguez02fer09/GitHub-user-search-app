## Checklist de Aceptación - Testing Manual

- [ ] Búsqueda con Enter y botón funciona.
- [ ] Estado de carga visible durante la búsqueda.
- [ ] Usuario válido muestra: avatar, nombre, login, bio, repos, followers,
      following.
- [ ] Fecha de alta formateada ("Joined dd Mon yyyy").
- [ ] Enlace a GitHub abre en nueva pestaña.
- [ ] Enlaces de blog/twitter activos solo si hay dato.
- [ ] Campos vacíos muestran "Not Available" y estilo deshabilitado.
- [ ] Mensaje claro para usuario inexistente.
- [ ] Manejo de error de red/rate limit sin crash.
- [ ] Toggle tema claro/oscuro estable; contraste suficiente.
- [ ] Responsive correcto en 360px, 768px, 1280px.
- [ ] Navegación por teclado con foco visible.
- [ ] Input de búsqueda tiene label/aria-label descriptivo.
- [ ] Sin errores en consola durante flujos principales.
